# seawolves-engine

Android-форк [Storm Engine](https://github.com/storm-devs/storm-engine) (движка серии «Корсары» / Sea Dogs).
На нём работает Seawolves — приложение, чтобы играть в «Корсары: Каждому своё» на телефоне
со своей копией игры. Лицензия GPL-3.0.

**Файлов игры здесь нет и не будет.** Нужна своя легально полученная копия. Приложение копирует её через
системный выбор файлов: папку с установленной игрой, архив или установщик. В версии для GitHub можно также
добавить свою раздачу (torrent или magnet) — ссылок на игру приложение не содержит.

## Чем отличается от оригинального движка

- Рендер на [bgfx](https://github.com/bkaradzic/bgfx) (OpenGL ES 3.0 или Vulkan) вместо DirectX 9; старый код
  рисует через прослойку, повторяющую интерфейс D3D9.
- Сенсорный интерфейс на RmlUi вместо оригинальных экранов.
- Жизненный цикл Android: сворачивание и возврат, автосохранение при уходе в фон, логи и диагностика.
- Графика: карты рельефа, нормалей и глянца, которые нейросети PBRify делают прямо на телефоне из файлов игры;
  параллакс на камне, дереве и штукатурке; переработанные освещение и тени; волны от кораблей и персонажей;
  мокрые поверхности в дождь; дальние LOD островов, кораблей и локаций; нейросетевое ×2 увеличение текстур.
- Оптимизация под телефоны: фоновая подготовка ресурсов с кэшем, учёт нагрева, пресеты качества.

## Что проверялось

Только «Корсары: Каждому своё». Другие игры на этом движке (Caribbean Legend, более старые «Корсары»)
не поддерживаются и не проверялись.

## Требования

Android 7.0 (API 24) и новее, 64-битный ARM (arm64-v8a), GPU с OpenGL ES 3.0. По умолчанию используется
Vulkan 1.1, если устройство поддерживает нужное игре и проходит самопроверку при запуске; иначе, а также после
сбоя Vulkan на этом драйвере, игра работает на OpenGL ES (пишется в лог и видно в настройках графики).
`render_backend = gles | vulkan` в engine.ini выбирает API принудительно. Форматы текстур и эффекты
выбираются по возможностям GPU, а отключённое пишется в лог.

## Сборка

Этот репозиторий собирает только нативную библиотеку движка, без APK:
`bash tools/android/ci_dependencies.sh`, затем `bash tools/android/ci_engine.sh`
(подробности — [tools/android/README.md](tools/android/README.md)). Сборка под Linux-хост для разработки —
см. `cmake/host.cmake`. Само Android-приложение, Seawolves, живёт в отдельном репозитории, который пока не публичен.

## Если нашли ошибку

В игре откройте «О программе» → «Поделиться логом» и приложите лог к сообщению. Если ошибка связана
с сохранением, там же есть «Отправить сохранение». Ошибки заводите в
[Issues](https://github.com/maxyo/seawolves-engine/issues) этого репозитория, приложив лог.
